# 康养云 · 智慧康复互联平台

以黎药特色与智慧康复为主题的静态展示站。只使用 HTML、CSS 和原生 JavaScript，无构建步骤、框架、在线字体或 CDN 依赖。

## 预览

直接打开 index.html 即可浏览。若需体验浏览器支持的跨文档切换动画，可通过任意静态 HTTP 服务器预览。

## GitHub Pages

1. 将本目录文件提交到 GitHub 仓库，保留 assets 目录与 8 个服务详情页。
2. 在仓库 Settings → Pages 中选择 Deploy from a branch。
3. 选择存放这些文件的分支及 / (root)，保存并等待部署完成。

所有站内资源和页面都使用相对路径，支持 https://用户名.github.io/仓库名/ 的项目站点，也支持自定义域名。每个详情页可直接打开和刷新，无需路由重写。无需 npm install 或构建命令。

## 文件说明

- index.html：首页、服务筛选与预约体验。
- 其余 8 个 HTML 文件：服务特色、流程、人群和前后服务导航。
- styles.css：草木绿与暖白配色、响应式布局、渐进式页面过渡。
- script.js：菜单、栏目高亮、筛选、弹窗及表单校验。
- assets/：本地矢量插画与图标。
- .nojekyll：直接托管静态资源。

## 功能边界

本站是服务展示与流程演示。预约信息仅在当前页面内预览，不发送、不保存，刷新后消失。用户和机构入口显示筹备说明，不采集密码，也不模拟真实登录。原项目的服务介绍保留；正式发布医疗服务前应由运营方核实具体服务能力与内容，并补充真实联系方式。

支持键盘导航、弹窗焦点管理、减少动态效果偏好。浏览器不支持跨文档 View Transitions 时使用普通页面跳转。关闭 JavaScript 时，服务内容和真实页面链接仍可使用。
